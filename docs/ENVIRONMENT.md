# Environment Configuration Reference

| Variable | Description | Example |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Token provided by @BotFather | `123456789:ABC...` |
| `TELEGRAM_BOT_USERNAME` | Handle of the Telegram Bot | `HendyAppStoreBot` |
| `TELEGRAM_ADMIN_IDS` | Comma-delimited admin IDs | `123456789,987654321` |
| `API_ADMIN_KEY` | Header key for admin REST endpoints | `hendy_admin_secret_key` |
| `D1_DATABASE_ID` | Cloudflare D1 database UUID | `d1-prod-hendy-001` |
| `KV_FEATURE_FLAGS_ID` | Cloudflare KV for feature flags | `kv_ff_001` |
| `KV_MAINTENANCE_ID` | Cloudflare KV for maintenance state | `kv_maint_001` |
